# 地軸傾斜與日出日落 - 互動教學 (Earth Axial Tilt)

給小朋友的互動天文課：**地球歪歪的，日出就會搬家？**

左邊看「陽光怎麼照到傾斜的地球」，右邊看「臺灣天空中，太陽從哪裡升起、從哪裡落下」。選季節、拖曳太陽，最後把地軸調成 0° 試試看！

## 🌐 線上預覽 (GitHub Pages)

- 靜態網站連結：[https://wells-huang.github.io/earth_axial_tilt/](https://wells-huang.github.io/earth_axial_tilt/)

## 🚀 功能特點

- **四季陽照互動**：春分、夏至、秋分、冬至的光照變化模擬
- **地軸傾角調整**：可手動調整 0° ~ 23.5°，直觀感受地軸傾角對日照與季節的影響
- **日夜天色與時鐘模擬**：即時觀察太陽在天空的升起與落下軌跡，以及白晝長短變化
